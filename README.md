# Odin Todo List

A simple and elegant Todo List app built with JavaScript and Webpack, inspired by The Odin Project curriculum.

## Live Demo

Check out the live version here: [Odin Todo List Live Demo](https://odin-todo-list.netlify.app/)

## Features
- Create multiple projects and tasks
- Set priorities, due dates, and notes
- Edit, complete, and delete tasks
- Persistent data saved in localStorage
- Responsive UI with task filtering
